# HP Forma fonts for HP-OS

HP Forma DJR Office Regular and Medium are distributed unmodified with HP-OS
under explicit authorization from HP, confirmed by Jonathan on 8 Nov 2026.
The font binaries retain their original embedded copyright and naming metadata.
This authorization covers their inclusion in HP-OS; it does not relicense the
fonts under the repository software license.

Source: the HP-provided PDF and presentation kit assets used for HP-OS branding.
